# Salverna

Juego narrativo para móvil en vertical: una casamentera gestiona una temporada social de 6 semanas en Valcenda.

- `produccion/PLAN-MAESTRO.md`: plan, estado y memoria del proyecto.
- `proyecto/`: paquete para programar (canon, sistemas, datos y textos ES/EN).
- `diseno/`: dirección de arte, pantallas y prompts de imágenes.
- `herramientas/`: corrección de tono de las imágenes.
- `archivo/juego-anterior/`: proyecto Ren'Py previo, archivado y ajeno a Salverna.
